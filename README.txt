HOW TO MAKE THIS YOURS
=======================

1. Open index.html in any text editor (Notepad, TextEdit, VS Code, etc).
   Find the block near the bottom that starts with:

     const CONFIG = {

   Everything you'd want to change lives in there:
   - her name
   - the hero subtitle
   - photo captions
   - rotating quotes
   - "reasons I love you" list
   - the quiz questions and answers
   - the love letter text
   - the final "make a wish" message

2. Add real photos:
   - Put your image files inside the "photos" folder.
   - Name them 1.jpg, 2.jpg, 3.jpg... (or update the file names inside
     CONFIG to match whatever you used).
   - Until you add real photos, the site shows a cute placeholder so you
     can preview the layout.

3. Add a video (optional):
   - Put one video file inside the "videos" folder, e.g. message.mp4
   - Make sure the name matches CONFIG.video.src (default: videos/message.mp4)

4. Add background music (optional):
   - Put one mp3 file inside the "music" folder, e.g. song.mp3
   - Make sure the name matches CONFIG.music.src (default: music/song.mp3)
   - There's a small music note button in the bottom-right corner she can
     tap to play/pause. Most browsers block audio from auto-playing, so
     it also tries to start automatically the moment she taps the
     envelope open (a real tap), which usually works.
   - If you skip this step, the button just won't do anything — nothing
     breaks.

5. Preview it:
   - Just double-click index.html to open it in your browser.
   - Reload after every change to see it update.

6. Send it to her:
   - Easiest: zip this whole folder and send it to her, she double-clicks
     index.html to open it.
   - Or host it for free in a couple of minutes on Netlify Drop
     (netlify.com/drop) or GitHub Pages, then just send the link.

Have fun with it. The whole thing is one file (index.html) plus your
photos/videos, so it's easy to keep tweaking.
